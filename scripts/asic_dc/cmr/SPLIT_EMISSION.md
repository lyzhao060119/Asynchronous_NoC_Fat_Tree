# Split network RTL emission

Run `powershell -File scripts/asic_dc/cmr/emit_split_1024.ps1` from the repository.
Outputs: `generated_cmr/split1024_20261020/{m16,mesh}`.

`top/` contains only wiring and router wrappers generated by the existing
network Scala classes. During this elaboration an in-process switch substitutes
each router body with a blackbox keyed by every constructor argument.
Normal elaboration defaults to real router bodies.

`routers.tsv` lists unique coordinate/geometry/routing configurations.
`children/<ref>/` contains independently emitted real RTL and blackbox resources;
`EMIT_PASS` is written only after emission finishes. Resume rejects changed
source/environment hashes. Each child is an independent DC compilation unit:
helper module names repeat across directories, so do not concatenate raw child
RTL files. Link mapped, uniquely named child DDCs into `top/` and stitch.
Existing monolithic hierarchical launchers require adaptation to this filelist;
their fixed CMRRouter_N parser must not silently accept this bundle as monolithic.

M16-1024 uses the existing 16-tile / 16-plane implementation: 768 tree routers
and 256 mesh routers. Deduplication is exact constructor-key reuse, including
coordinates, mesh grid size and coordinate shift. Flat Mesh uses 1024 unique
coordinate keys. The default tree RCU DEL100 / mesh RCU DEL150 are retained.
Final acceptance requires `CMR_SPLIT_EMIT_PASS` for both networks, all child
markers/files, matching wrapper/child ports and frozen artifact hashes.
