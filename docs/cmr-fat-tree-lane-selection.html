CMR Fat-tree：一个 IPM direction branch 到多条物理 OPM lane

示例为 L1 Router 的 child 输入发往 parent 方向：parent 有 lane 0、lane 1。IPM / OPM 内部细节省略，只画中间扩展互联、两级仲裁和两相相位适配。

选择顺序

  1. IPM 的 RCU 已为一个方向置位 PathEnabled。
  2. Selector 排除被其他 source 占用的 lane，并以 CMRMutexN(2) 选出 one-hot LaneSelect。
  3. 所选 lane 的 OPM 在所有 ingress 竞争者中给出 Grant[source]。
  4. Commit = LaneSelect AND Grant 后，Adapter 才让该 lane 看见转换后的 Req。

释放顺序

  • 选中 OPM 检测到 Tail 后，对该 source 产生 TailPassed。
  • 只允许 committed lane 的 TailPassed 回到该 IPM direction branch。
  • IPM 清除该方向的 PathEnabled，进而释放 OPM / lane 资源。
  • 下一个 packet 才能重新选择 lane；这正是 CMR-TP-01 要约束的时序边界。
