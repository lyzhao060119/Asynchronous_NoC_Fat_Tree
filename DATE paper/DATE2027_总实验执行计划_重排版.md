## 共同验收规则

- 归档保留 raw、summary、acceptance、manifest、hash、命令和 `RESULTS.md`。每项结论按具体 case/claim 判定，不直接改写历史 `paper_eligible=false`。
- MAXIMUM-SDF GLS：`Total errors: 0`、`TB_RESULT PASS`、零 missing/unexpected/timeout/X/fatal、full-drain 计数一致。任何失败或未完成点显式标为 blocked/exploratory。
- 负载扫点的 latency 正向结论只取 near-lossless 点；饱和点可以报告 delivered throughput，但须标出 censored/saturation。
- 不 `git pull`、不 stash、不重新综合已有网表；记录归档时实际 commit、dirty state 与输入 SHA-256。所有新 run 使用新时间戳。
